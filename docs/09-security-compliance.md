# 09 安全与合规

> 私有化交付的安全评审，通常在**合同签订之后、上线之前**进行。银行、政务、央国企客户会拿一份几百项的检查表来对；本章给出最常被卡住的几类，以及能在交付现场直接执行的动作。
>
> 本章不是法律意见。等保、密评、行业监管的具体条款请以客户方安全部门与第三方测评机构的要求为准。

## 9.1 交付前必须澄清的四件事

| 问题 | 为什么必须先问 | 影响 |
| --- | --- | --- |
| 是否需要过**等保 2.0**？几级？ | 三级要求日志留存 6 个月、双因素、审计分离 | 决定是否要额外部署日志平台与堡垒机 |
| 是否要求**密评**（商用密码应用安全性评估）？ | 密评要求国密算法（SM2/SM3/SM4）与密钥管理 | 决定 TLS 证书、落盘加密方案，开源组件默认不满足 |
| 数据能否**出客户机房**？ | 决定能否远程运维、能否回传日志 | 影响运维成本与响应时效 |
| 模型许可证是否被客户法务接受？ | 部分模型禁止商用或限制用户数 | 决定选型，签合同前就要确认 |

> ⚠️ 这四条如果等到实施阶段才问，返工成本最高：密评不通过可能要求换 TLS 方案甚至换部署架构。

## 9.2 访问控制与密钥

**最低要求**（所有项目都应做到）：

```bash
# API Key 必须非空启动。空变量会让服务以空 key 接受所有请求
: "${API_KEY:?API_KEY is required}"
vllm serve ... --api-key "${API_KEY}"
```

```bash
# 不要把 key 写进 compose / systemd 明文
# 用文件挂载 + 权限 600，或客户提供的密钥管理服务
install -m 600 /dev/null /etc/llm/api.key
```

| 项 | 做法 | 验证方式 |
| --- | --- | --- |
| API Key | 每环境独立；交付时随机生成，不沿用测试值 | `curl` 不带 key 应返回 401 |
| 密钥轮换 | 约定周期（如 90 天）与轮换责任人 | 轮换演练一次并记录 |
| 管理面隔离 | 推理端口只对业务网开放，管理端口只对运维网 | `ss -tlnp` + 防火墙规则核对 |
| 传输加密 | 前置网关做 TLS；证书由客户提供或使用其 CA 签发 | `openssl s_client` 检查证书链 |
| 模型文件权限 | 权重目录 750，属主为服务账号 | `ls -l` 抽查 |

## 9.3 日志与数据

| 类别 | 建议 | 说明 |
| --- | --- | --- |
| 请求日志 | **默认不记录 prompt / 回答正文** | 记录 request_id、token 数、耗时、状态码即可 |
| 必须记录正文时 | 客户书面同意 + 脱敏 + 单独存储 + 访问审计 | 脱敏至少覆盖手机号、身份证、银行卡、邮箱 |
| 留存期 | 按客户合规要求（等保三级常见 ≥6 个月） | 提前算好日志盘容量：`日请求量 × 单条大小 × 留存天数` |
| 审计日志 | 谁在何时调用了哪个模型 / 查看了哪份日志 | 与业务日志分离，普通账号不可删改 |
| 训练数据回流 | **默认关闭**，任何回流须书面授权 | 私有化项目最常见的合规雷区 |

## 9.4 供应链：镜像、模型、补丁

```bash
# 1) 用 digest 固定镜像，不用 tag
docker pull vllm/vllm-openai@sha256:<digest>
docker inspect --format '{{index .RepoDigests 0}}' vllm/vllm-openai:<tag>

# 2) 生成 SBOM（推荐 syft），随交付文档一起归档
syft vllm/vllm-openai@sha256:<digest> -o spdx-json > sbom.spdx.json

# 3) 漏洞扫描（推荐 grype / trivy），高危必须闭环
grype sbom:sbom.spdx.json -o table

# 4) 模型权重校验：落地后记录每个分片的 sha256，交付时核对
sha256sum /models/<model>/*.safetensors > weights.sha256
```

| 项 | 要求 | 归档物 |
| --- | --- | --- |
| 镜像 | digest 固定 + 签名（cosign 或客户认可的方案） | 镜像清单 + SBOM + 扫描报告 |
| 模型 | 来源、许可证、sha256 清单 | 模型清单 + 许可证明 |
| 补丁 | 离线包 + 签名 + 回滚包 | 补丁记录表 |
| 依赖 | Python 依赖版本冻结（`pip freeze`） | requirements.lock |

> ⚠️ `--trust-remote-code` 会执行模型仓库里的任意 Python 代码。生产环境应在**离线镜像**里预置模型代码，并在评审时说明：它执行了什么、来源是否可信、有没有做过代码审阅。

## 9.5 模型许可证

| 模型 | 许可证 | 常见限制 |
| --- | --- | --- |
| Qwen 系列 | Apache-2.0（多数） | 部分尺寸另有条款，以模型卡为准 |
| Llama 系列 | Llama Community License | 月活用户超阈值需单独授权 |
| DeepSeek 系列 | 自有许可 | 需核对商用条款与署名要求 |
| Mistral 系列 | Apache-2.0 / MRL 双轨 | 部分权重仅研究用途 |

**交付动作**：把所选模型的许可证原文、版本、获取日期一起放进交付文档；客户法务确认后再上线。

## 9.6 安全评审自查表

| # | 检查项 | 证据 | 通过 |
| --- | --- | --- | --- |
| 1 | 等保级别已澄清 | 会议纪要 / 需求确认书 | ⬜ |
| 2 | 是否需要密评已确认 | 需求确认书 | ⬜ |
| 3 | API Key 非空且已交付 | 启动命令 + 401 验证记录 | ⬜ |
| 4 | 管理面与业务面网络隔离 | 防火墙规则截图 | ⬜ |
| 5 | TLS 证书链有效 | `openssl s_client` 输出 | ⬜ |
| 6 | 日志不含正文（或已授权+脱敏） | 日志样例 | ⬜ |
| 7 | 日志留存满足要求且容量足够 | 容量计算表 | ⬜ |
| 8 | 镜像 digest 固定 | 镜像清单 | ⬜ |
| 9 | SBOM 与漏洞扫描报告已归档 | sbom / 扫描报告 | ⬜ |
| 10 | 模型许可证已获客户确认 | 法务确认邮件 | ⬜ |
| 11 | 补丁与回滚包已准备 | 补丁记录表 | ⬜ |
| 12 | 数据不出机房已确认（或已授权） | 需求确认书 | ⬜ |
